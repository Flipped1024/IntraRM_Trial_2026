# 电脑键盘调试程序：使用方法

第一次使用时，先安装 CH340 驱动，再连接 USB 转串口模块。之后打开 `RM_PC_Controller.exe` 即可。

## 一、安装 CH340 驱动

1. 双击本文件夹里的 `CH341SER.EXE`。如果 Windows 弹出“用户账户控制”，选择“是”。也可以右键程序，选择“以管理员身份运行”。
2. 在安装程序窗口点击 **安装**，等待弹出**驱动安装成功**即可
3. 使用USB连接主控板。右键点击 Windows 开始按钮，打开“设备管理器”，展开“端口（COM 和 LPT）”。确认列表中出现 `USB-SERIAL CH340 (COMx)` 即为安装成功。

`CH341SER.EXE` 是沁恒电子签名的驱动安装文件。若安装后设备管理器中仍没有串口，请拔下并重新插入模块、重启电脑，然后再检查设备管理器。也可以在设备管理器里右键该设备，选择“卸载设备”，拔下模块后重新插入并重试。

## 二、连接主控并打开程序

1. 按接线要求连接主控。
2. 双击 `RM_PC_Controller.exe`。
3. 点击“刷新”。列表会显示设备名称和描述；识别到的 CH340 会在 COM 编号旁标出。选择对应串口并点击“连接”。
4. 点击“连接”后，程序默认把控制权留给手柄。需要用键盘时，先松开所有按键，再点击“启用键盘”。

程序打开时会自动切换到 Windows 英文键盘布局，避免中文输入法影响字母键和空格键。关闭程序后会恢复打开前的键盘布局。

如果列表里有多个串口，或者不确定选哪个，可以拔下 CH340，点击“刷新”记下少掉的端口；再插回 CH340 并刷新，新增的端口就是这个模块。

## 三、键盘操作

| 按键 | 功能 |
|---|---|
| W / S | 底盘前进 / 后退 |
| A / D | 底盘左移 / 右移 |
| Q / E | 底盘转向，对应手柄 LB / RB |
| ↑ / ↓ | 云台 Pitch 上下 |
| ← / → | 云台 Yaw 左右 |
| 开火键 | 按住拨弹，松开停止；对应手柄 RT |
| 摩擦轮键 | 每按一次切换摩擦轮开关；对应手柄 A |
| Esc / “停止键盘并交还手柄” | 停止键盘控制，并把控制权交还手柄 |

程序默认用**空格**开火、用**左 Shift**切换摩擦轮。想换按键时，点击窗口里的“开火 / RT”或“摩擦轮 / A”按钮，再按想设置的按键。两个功能不能使用同一个按键。按 Esc 可取消正在进行的按键设置。新设置会保存在本文件夹的 `keybindings.ini` 中，下次打开程序仍会使用。

底盘摇杆幅度默认为 **75%**，可选择 25%、50%、75% 或 100%。该设置只调整 WASD 的底盘输入；Q/E 转向和云台输出保持原有力度。

## 四、手柄与键盘切换

- 键盘未启用时，手柄照常控制小车。
- 键盘启用时，电脑键盘优先控制小车。
- 按 Esc、点击停止按钮、切到其他窗口或断开串口后，控制权交还手柄。再次使用键盘时，需要回到程序窗口并重新点击“启用键盘”。
- 主控收不到电脑数据时会停止键盘输入；如果手柄正在发送有效数据，主控会恢复手柄控制。

“停止键盘”会交还手柄。如果手柄仍在推动摇杆或按着 RT，小车会继续响应手柄。需要小车停止时，也要松开手柄按键并将摇杆回中。

## 五、连接不上时

- **设备管理器里没有 CH340 串口**：按第一部分安装驱动，然后拔插模块。
- **程序里没有对应 COM 口**：点击“刷新”，或重新插拔模块。
- **点击连接后打不开串口**：关闭正在使用该 COM 口的串口助手或其他程序，再试一次。
- **程序显示已发送，但小车没有反应**：检查主控是否烧录新版固件、TXD 和 GND 是否接对，以及设备是否处于正常遥控模式。

USB 转串口使用 3.3 V TTL 信号：CH340 的 TXD 接主控 PB7，GND 与主控 GND 相连。首次测试请让车轮离地，并确认拨弹机构中没有弹丸。

## 发给操作者的文件

- 对方已安装 CH340 驱动：只需发送 `RM_PC_Controller.exe`。
- 对方未安装驱动：同时发送 `CH341SER.EXE`。
- 要让对方沿用你设置的开火和摩擦轮按键：再发送 `keybindings.ini`，并与 EXE 放在同一个文件夹。

图片、源代码、编译器、测试文件和主控板固件都不需要随程序发送。程序图标和背景已经放在 EXE 里。

如果程序连续 5 秒没有响应，程序会自动退出，避免卡死后一直占用串口。重新双击程序即可再次使用；如果主控仍在接收控制数据，请确认键盘已停用或重新连接后先发送停止状态。

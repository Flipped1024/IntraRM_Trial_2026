# Main Board

主控板固件，基于 STM32F407IGH6，通过 CAN 总线与底盘驱动板、云台驱动板通信，接收遥控器 SBUS 指令，实现底盘运动学解算和云台控制。

## 硬件平台

- **MCU**：STM32F407IGH6
- **CAN 总线**：CAN1, 1 Mbps（PD0 RX, PD1 TX）
- **遥控器**：USART3, 100 kbps, DMA 接收（SBUS 协议）
- **控制频率**：100 Hz（10ms 周期）

## CAN 通信协议

### 底盘下发帧：主控 → 驱动板

**CAN ID：`0x111`（驱动板 #1）/ `0x112`（驱动板 #2）**，标准帧，数据长度 8 字节。

| 字节偏移 | 数据类型 | 字段 | 说明 |
|----------|----------|------|------|
| 0 - 1 | `int16_t` | 电机 1 转速 | 目标转速，单位：RPM |
| 2 - 3 | `int16_t` | 电机 2 转速 | 目标转速，单位：RPM |
| 4 - 7 | — | 预留 | — |

### 底盘上报帧：驱动板 → 主控

**CAN ID：`0x222`（驱动板 #1 速度）/ `0x223`（驱动板 #1 位置）/ `0x224`（驱动板 #2 速度）/ `0x225`（驱动板 #2 位置）**，标准帧，数据长度 8 字节。

**速度帧（0x222 / 0x224）**：

| 字节偏移 | 数据类型 | 字段 | 说明 |
|----------|----------|------|------|
| 0 - 1 | `int16_t` | 电机 1 当前速度 | 单位：RPM |
| 2 - 3 | `int16_t` | 电机 2 当前速度 | 单位：RPM |
| 4 - 7 | — | 预留 | — |

**位置帧（0x223 / 0x225）**：

| 字节偏移 | 数据类型 | 字段 | 说明 |
|----------|----------|------|------|
| 0 - 3 | `int32_t` | 电机 1 当前位置 | 编码器累计脉冲 |
| 4 - 7 | `int32_t` | 电机 2 当前位置 | 编码器累计脉冲 |

### 云台下发帧：主控 → 云台驱动板

**CAN ID：`0x113`**，标准帧，数据长度 8 字节。协议与云台驱动板文档一致，详见 [Gimbal.md](Gimbal.md)。

| 字节偏移 | 数据类型 | 字段 | 说明 |
|----------|----------|------|------|
| 0 - 3 | `int32_t` | 目标位置 | Pitch 轴目标位置，单位：0.01° |
| 4 - 5 | `int16_t` | 摩擦轮占空比 | 范围 [0, 999] |
| 6 - 7 | `int16_t` | 拨弹盘占空比 | 范围 [-999, 999] |

### 云台上报帧：云台驱动板 → 主控

**CAN ID：`0x206`**，标准帧，数据长度 8 字节。

| 字节偏移 | 数据类型 | 字段 | 说明 |
|----------|----------|------|------|
| 0 - 1 | `int16_t` | 当前速度 | Pitch 轴当前速度，单位：RPM |
| 2 - 5 | `int32_t` | 当前位置 | Pitch 轴当前位置，单位：0.01° |
| 6 - 7 | — | 预留 | — |

## 遥控器（SBUS）

通过 USART3 DMA 空闲中断接收 SBUS 协议帧，解析出摇杆、开关、键盘、鼠标数据。

### 遥控器数据结构

| 字段 | 来源 | 说明 |
|------|------|------|
| `ch1_` | 右摇杆水平 | 底盘旋转速度 vw，范围 [-660, 660] |
| `ch2_` | 右摇杆垂直 | 云台 Pitch 轴位置，范围 [-660, 660] |
| `ch3_` | 左摇杆垂直 | 底盘前后速度 vy，范围 [-660, 660]（带100死区） |
| `ch4_` | 左摇杆水平 | 底盘左右速度 vx，范围 [-660, 660]（带100死区） |
| `wheel_` | 拨轮 | 备用 |
| `switch_left_` | 左开关 | 1=上, 2=下, 3=中 → 拨下切换摩擦轮/拨弹盘开关 |
| `switch_right_` | 右开关 | 1=上, 2=下, 3=中 |
| `mouse_` | 鼠标 | x, y, z 及左右按键 |
| `key_code_` | 键盘 | 16 位键码掩码 |
| `state_` | 连接状态 | 0=断开, 1=连接 |

## 底盘运动学

底盘采用麦克纳姆轮布局，4 个轮子分别由 2 块驱动板控制。主控将遥控器指令（vx, vy, vw）通过麦克纳姆轮逆运动学解算为 4 个轮子的目标转速。

### 底盘参数

| 参数 | 符号 | 值 | 单位 |
|------|------|------|------|
| 底盘半径 | `Lc` | 0.17888 | m |
| 车轮半径 | `R` | 0.0765 | m |
| 最大转速 | — | 12000 | RPM |

### 运动学公式

```
ω_FL = -((√2/2·(-vx - vy) + Lc·vw) / R · 60)
ω_FR = -((√2/2·(-vx + vy) + Lc·vw) / R · 60)
ω_RL = -((√2/2·(vx + vy) + Lc·vw) / R · 60)
ω_RR = -((√2/2·(vx - vy) + Lc·vw) / R · 60)
```

### 电机分配

| 驱动板 | CAN ID | 电机 1 | 电机 2 |
|--------|--------|--------|--------|
| #1 | 0x111 | 左前轮 (FL) | 右前轮 (FR) |
| #2 | 0x112 | 左后轮 (RL) | 右后轮 (RR) |

## 云台控制

主控不直接控制云台电机，而是通过 CAN 总线向云台驱动板下发目标位置和摩擦轮/拨弹盘占空比。云台驱动板内部完成 PID 闭环控制。

### 标定流程

上电后自动执行三阶段标定，确定云台机械限位和零点：

```
GIMBAL_STATE_CALIB_UP    → 向上运动直到堵转，记录上机械限位
GIMBAL_STATE_CALIB_DOWN  → 向下运动直到堵转，记录下机械限位
GIMBAL_STATE_CALIB_CENTER → 回到中心位置，等待稳定
GIMBAL_STATE_READY       → 标定完成，进入正常遥控模式
```

### 正常模式

- 遥控器右摇杆垂直方向（ch2）控制 Pitch 轴角度
- 摇杆行程 [-660, 660] 映射到标定范围 [-range, +range]
- 遥控器左开关拨下切换摩擦轮和拨弹盘开关

### 标定参数

| 参数 | 值 | 说明 |
|------|------|------|
| 标定速度 | 100 | 标定运动速度，单位：0.01°/步 |
| 堵转判定时间 | 500 ms | 持续低于速度阈值判定为堵转 |
| 堵转速度阈值 | 5 | 低于此值判定为堵转 |
| 稳定等待时间 | 300 ms | 堵转后等待稳定时间 |

```
    │   └── chassisSendCmd()       CAN 下发 0x111/0x112

```

## Ozone 在线调试

通过 SWD 连接 Ozone 调试器，在 Watch 窗口添加全局变量 `g_debug_`，即可实时查看和修改调试参数。

### 操作步骤

1. 用 J-Link 通过 SWD 连接主控板
2. 打开 Ozone，加载工程的 `.elf` 文件
3. 在 **Watch** 窗口中添加变量名：`g_debug_`
4. 展开结构体，可看到所有调试信息和参数

### 调试模式切换

通过 Ozone 修改变量 `g_debug_.mode_` 切换调试模式：

| 模式值 | 宏 | 说明 |
|--------|------|------|
| 0 | `DEBUG_MODE_NONE` | 正常模式，遥控器控制底盘和云台 |
| 1 | `DEBUG_MODE_CHASSIS` | 底盘调试模式，通过 Ozone 直接设置 vx/vy/vw |
| 2 | `DEBUG_MODE_CAN` | CAN 直发模式，通过 Ozone 直接设置 4 个电机 RPM |

### 底盘调试模式字段

| 字段 | 类型 | 可写 | 说明 |
|------|------|------|------|
| `chassis_.vx_` | `float` | **是** | 底盘 x 方向速度 |
| `chassis_.vy_` | `float` | **是** | 底盘 y 方向速度 |
| `chassis_.vw_` | `float` | **是** | 底盘旋转速度 |

### CAN 调试字段

| 字段 | 类型 | 可写 | 说明 |
|------|------|------|------|
| `motor_rpm_[0..3]` | `int16_t` | **是** | 4 个电机目标转速（CAN 直发模式） |
| `tx_count_` | `uint32_t` | 否 | CAN 发送次数 |
| `tx_ok_count_` | `uint32_t` | 否 | CAN 发送成功次数 |
| `tx_fail_count_` | `uint32_t` | 否 | CAN 发送失败次数 |
| `rx_count_` | `uint32_t` | 否 | CAN 接收次数 |
| `last_rx_id_` | `uint32_t` | 否 | 最近收到的 CAN ID |
| `last_rx_data_[8]` | `uint8_t` | 否 | 最近收到的 CAN 数据 |
| `can_state_` | `uint32_t` | 否 | CAN 外设状态 |
| `can_error_` | `uint32_t` | 否 | CAN 错误码 |
| `can_tx_mailbox_free_` | `uint32_t` | 否 | CAN 空闲邮箱数 |

> 在 Watch 窗口中双击参数值即可修改，**下一个控制周期（10ms内）立即生效**，无需重新编译烧录。

## 构建与烧录

使用 VS Code Makefile 打开工程编译后，通过 SWD 或串口烧录。

- 编译器：`arm-none-eabi-gcc`
- 编译标准：C11
- 优化等级：`-Og`（调试阶段）
- 硬件浮点：`fpv4-sp-d16`（硬浮点 ABI）

```bash
# 编译
make -j

# 清理
make clean

# 烧录（通过 J-Link / Ozone 加载 .elf）
```

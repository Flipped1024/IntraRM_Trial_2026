# CAN 总线通信协议说明 (主控 ⇌ 底盘电机驱动板)

## 1. 通信总则

* **字节序 (Endianness)**: 大端模式 (Big-Endian) —— 高位字节 (MSB) 在前，低位字节 (LSB) 在后。
* **数据类型**:
* 速度数据：有符号 16 位整型 (`int16_t`)
* 位置数据：有符号 32 位整型 (`int32_t`)


* **报文类型**: 标准帧。

---

## 2. 下发帧：主控发送控制指令

主控负责向驱动板发送左右电机的目标速度。

* **Message ID (Hex)**: `0x111`
* **发送频率**: 由主控端决定（通常结合底盘控制周期，建议 1ms - 5ms）
* **数据长度**: 4 Bytes 有效数据（若使用 8 Bytes 发送，后 4 字节将被驱动板忽略）

| Byte 偏移量 | 字段含义                    | 数据类型  | 拼接解析说明 |
| ----------- | --------------------------- | --------- | ------------ |
| `Byte[0]`   | 1号电机目标速度 (High Byte) | `int16_t` | 速度高 8 位  |
| `Byte[1]`   | 1号电机目标速度 (Low Byte)  | `int16_t` | 速度低 8 位  |
| `Byte[2]`   | 2号电机目标速度 (High Byte) | `int16_t` | 速度高 8 位  |
| `Byte[3]`   | 2号电机目标速度 (Low Byte)  | `int16_t` | 速度低 8 位  |

> **⚠️ 注意**:
> 下发前请对目标速度值执行强制类型转换并按位右移。示例：
> `tx_buf[0] = (uint8_t)(left_target >> 8);`
> `tx_buf[1] = (uint8_t)(left_target & 0xFF);`

---

## 3. 上报帧：驱动板发送状态反馈

驱动板负责向主控定时上报电机的**当前速度**和**当前位置**（编码器累计值）。为了避免总线拥堵与单帧超载，数据拆分为两帧发送。

### 3.1 速度反馈帧

* **Message ID (Hex)**: `0x222`
* **数据长度**: 8 Bytes（后 4 字节保留为 `0x00`）

| Byte 偏移量 | 字段含义                    | 数据类型  | 拼接解析说明    |
| ----------- | --------------------------- | --------- | --------------- |
| `Byte[0]`   | 1号电机当前速度 (High Byte) | `int16_t` | 速度高 8 位     |
| `Byte[1]`   | 1号电机当前速度 (Low Byte)  | `int16_t` | 速度低 8 位     |
| `Byte[2]`   | 2号电机当前速度 (High Byte) | `int16_t` | 速度高 8 位     |
| `Byte[3]`   | 2号电机当前速度 (Low Byte)  | `int16_t` | 速度低 8 位     |
| `Byte[4-7]` | 保留位                      | N/A       | 默认填充 `0x00` |

### 3.2 位置反馈帧

* **Message ID (Hex)**: `0x223`
* **数据长度**: 8 Bytes

| Byte 偏移量 | 字段含义              | 数据类型  | 拼接解析说明              |
| ----------- | --------------------- | --------- | ------------------------- |
| `Byte[0]`   | 1号电机当前位置 (MSB) | `int32_t` | 位置最高 8 位 (Bit 24-31) |
| `Byte[1]`   | 1号电机当前位置       | `int32_t` | 位置 (Bit 16-23)          |
| `Byte[2]`   | 1号电机当前位置       | `int32_t` | 位置 (Bit 8-15)           |
| `Byte[3]`   | 1号电机当前位置 (LSB) | `int32_t` | 位置最低 8 位 (Bit 0-7)   |
| `Byte[4]`   | 2号电机当前位置 (MSB) | `int32_t` | 位置最高 8 位 (Bit 24-31) |
| `Byte[5]`   | 2号电机当前位置       | `int32_t` | 位置 (Bit 16-23)          |
| `Byte[6]`   | 2号电机当前位置       | `int32_t` | 位置 (Bit 8-15)           |
| `Byte[7]`   | 2号电机当前位置 (LSB) | `int32_t` | 位置最低 8 位 (Bit 0-7)   |
